# 离线持久化设计（2026-09-30）

目标：页面下载一次后无需再次下载即可使用；断网也能打开；关闭浏览器再打开不重新下载。

## 三层机制

1. **Service Worker（`sw.js`，客户端根目录）**
   - `install`：预缓存 `./` 与 `./index.html`（app shell）。
   - `fetch`：仅同源 GET 走 cache-first；命中直接返回，未命中走网络并回填缓存。
     bundle 产物文件名带 hash（`assets/index-*.js`），不写死，用运行时缓存自适应。
   - `navigation` 请求离线时回退到缓存的 `./index.html`。
   - `activate`：删除旧版本 cache（`CACHE_VERSION` 升级时），`clients.claim()`。
   - 跨域请求（relay WebSocket/HTTP）一律放行，不拦截。
   - 发布新 bundle 时必须 bump `CACHE_VERSION`，否则用户拿到旧缓存。

2. **构建拷贝（`build.mjs`）**
   - SDK 的 `buildClient()` 只产出 bundle，不拷贝静态文件；构建后把 `sw.js`
     复制到 `dist/sw.js`，静态托管（`http://lulin.org/client/`）才能取到。
   - 入口 `src/main.tsx` 在 `window.load` 时注册 `./sw.js`，`serviceWorker in navigator`
     为 false 时静默跳过（纯 HTTP 站点非 secure context，SW 不可用）。

3. **帖子 feed 持久化（`src/App.tsx`）**
   - `loadCachedEvents()`：启动时从 `nostr-min-events-v1` 恢复，上限 `MAX_EVENTS`
     条；脏数据（kind 非 1、缺字段）丢弃，缺 `relays`/`tags` 补 `[]`。
   - `saveCachedEvents()`：节流（3 秒）写入 + `pagehide` 兜底；配额不足时静默跳过。
   - 实时事件按 id 去重合并，覆盖缓存的陈旧 `relays` 信息。

## 纯 HTTP 站点的限制

`http://lulin.org` 不是 secure context，浏览器禁用 Service Worker。
该环境下靠两样实现"重启免下载"：

- HTTP 磁盘缓存：`index.html`/`sw.js` 用 `Cache-Control: no-cache`（每次 revalidate，
  未改返回 304 不下载正文）；`assets/*` 用 `immutable` 一年缓存。
  具体 nginx 片段见 README。
- localStorage 持久化：relay 配置、profile、关注、帖子 feed 都在本地，
  打开即渲染，relay 连上后再刷新。
